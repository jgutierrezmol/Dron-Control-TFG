# Dron-Control-TFG

## Com executar la versió compilada (Release / Executable)
Per provar directament l'estat actual del joc sense necessitat d'instal·lar Unity:
1. Aneu a la secció **[Releases](../../releases)** d'aquest repositori (a la columna dreta).
2. Descarregueu el fitxer `.zip` corresponent al lliurament (ex. `DronControl_PAC2_Windows.zip`).
3. Descomprimiu **tot el contingut** del fitxer `.zip` en una carpeta local.
4. Executeu el fitxer `.exe` principal.

### Contingut del prototip actual (PAC 2):
* **Menu inicial:** Botons clickables jugar, opcions i sortir.
* **Menu opcions:** Tornar és l'unic boto clickable
* **Videojoc:** Pantalla esquematica de proposta de joc. Cap interració.
